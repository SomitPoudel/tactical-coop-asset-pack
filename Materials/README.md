# Materials and textures

The pack is intentionally designed around a small shared material palette to keep a low memory footprint and improve Unity import compatibility.

Planned shared set:
- concrete
- metal
- wood
- plastic
- fabric
- glass
- emissive bulb material
- tactical accent colour palette

Current status:
- material definitions are procedural in Blender scripts
- no textures or atlas maps were generated in this session
